# «Отчётик»: приложение прораба

Мобильное приложение к «Объективу»: прораб снимает результат работы одной кнопкой, фото
сохраняется на телефоне и досылается на сервер, когда есть сеть; статусы, факт и рейтинг
бригад приходят с сервера. По документу Татьяны `construction-monitoring/docs/FOREMAN_APP.md`.

## Как открыть

- Android: APK — ссылка появится здесь после сборки в EAS. Разрешить установку из файла.
- Любой телефон по ссылке: https://jas76123.github.io/obyektiv/ (в браузере; фото хранится
  в хранилище браузера, досылается пока вкладка открыта).

## Разработка

    npm install
    npx expo start          # Expo Go на телефоне или w для браузера
    npm test                # Vitest: контракт, статусы, источник, очередь, отправщик, лента
    npm run typecheck
    npm run build:apk       # EAS Build, профиль preview (APK)
    npm run deploy          # веб-версия в ветку gh-pages

## Стыковка с сервером

Контракт: `contract/README.md`, примеры ответов `demo/*.json`. Адрес сервера задаётся
в скрытой настройке: долгое нажатие на номер версии на экране входа. Пустой адрес или
переключатель «Только демо-данные» = работа на вшитых данных с пометкой «демо».

## Что где

    contract/   схемы ответов (zod)          data/    сервер → кэш → демо
    queue/      очередь фото, отправщик, фон  app/     экраны (Expo Router)
    demo/       демо-данные по сценарию       tests/   Vitest

## Ограничения

- Досылка в фоне на Android: не раньше чем через 15 минут и когда система решит; после
  принудительного закрытия приложения до следующего запуска. Основная досылка: при съёмке,
  при появлении сети, при открытии приложения.
- В браузере фоновой досылки нет, хранилище небольшое (порядка 10–15 фото).
- iOS-сборки нет (нужен платный аккаунт Apple); на iPhone работает веб-версия.
